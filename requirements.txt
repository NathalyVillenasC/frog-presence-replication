# Core numerics and tables
numpy
pandas

# Plotting. seaborn draws the statistical figures (categorical box + strip plots) and
# supplies the global theme, which removes the per-figure grid and spine styling.
matplotlib
seaborn

# Notebook environment
jupyter
ipykernel

# Testing. Runs the suite in tests/, which covers the reusable pieces extracted into
# src/frog_presence: header reading, filename classification and sidecar parsing.
pytest

# Configuration. Reads the dataset locations from a local .env file, so the paths
# stay out of the code and the notebook runs on any machine that has the data.
python-dotenv

# MATLAB file I/O. `scipy.io.loadmat` reads the .mat segment files shipped with the
# clean-call dataset, which hold the call boundaries the paper's Table 1 is built from.
scipy

# Mel filter banks. `librosa.filters.mel` builds the triangular bank the article's
# Figure 6(b) is estimated from, with the lower edge, the number of filters, the mel
# formula and the normalisation all given as named arguments.
librosa

# Audio I/O. Python binding to libsndfile; used to read audio file headers
# (sample rate, channels, duration, encoding) without decoding the samples.
# Required because part of the corpus is GSM 6.10 inside WAV and MP3, which
# neither the stdlib `wave` module nor `scipy.io.wavfile` can open.
soundfile

# Gaussian mixture models. `sklearn.mixture.GaussianMixture` is the article's classifier (section 3.5):
# EM maximum-likelihood training, k-means++ initialisation, diagonal covariances.
scikit-learn

# Model persistence. Trained mixtures and their thresholds are written to `models/` and
# reloaded by later notebooks, so a stage does not retrain what an earlier one produced.
joblib
